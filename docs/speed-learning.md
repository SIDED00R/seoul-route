# 안내 궤적과 사용자별 속도 학습 (이슈 #32, 2026-09-13)

계획 v2 의 Phase 2b(안내·foreground 위치 스트림·배치 업로드)와 Phase 3(속도 학습)을 한 기능으로 붙였다.
목표: 사용자가 실제로 걷고 따릉이를 탄 속도로 예상시간을 내는 것. 표본이 없으면 사전값(걷기 1.2·자전거 3.5 m/s)이다.

## 흐름

```
앱 상세 화면 "안내 시작"
 → POST /trips (trip id 발급)
 → 화면이 떠 있는 동안 5초마다 위치(geolocator, foreground) → 현재 구간 수단(walk/bicycle/transit) 태그
 → 20개(≈100초) 또는 30초마다 POST /trips/{id}/traces (실패분은 다음 배치 앞에 붙여 재전송, 요청당 최대 1000개, 서버는 (trip, ts) 중복 무시)
 → "안내 종료": 남은 샘플 flush(줄어드는 동안 반복, 실패하면 남긴 채 중단·재시도 안내) → POST /trips/{id}/end (409 면 이미 닫힌 것으로 보고 완료 처리)
    → 서버: 수단별 이동 중 중앙값(speed.TripSpeeds) → speed_profiles 수축 갱신 → 결과 대화상자
 → 다음 POST /routes/plan 부터 OTP walk/bicycle speed 에 내 속도가 들어간다
```

앱 `lib/guide/leg_tracker.dart` 가 현재 구간을 정한다: 위치가 현재 구간 끝점 40m 안에 들어오면 다음 구간으로, 손으로 앞뒤 이동도 된다.
샘플의 mode 는 그 시점 구간의 수단이다(WALK→walk, BICYCLE→bicycle, 탑승 구간→transit). transit 샘플은 저장만 하고 학습에 쓰지 않는다.

## 속도 산출 (`backend/internal/speed`)

| 단계 | 규칙 | 근거(초기값, 실기기 궤적으로 재보정) |
|---|---|---|
| 표본 필터 | accuracy ≤ 30m | 도심 GPS 반사 표본 제거 |
| 연속 쌍 | 같은 수단, 간격 2~30초 | 앱 5초 간격. 30초 넘게 비면 구간 속도가 아니다 |
| 속도 상한 | 걷기 3.0 · 자전거 12.0 m/s | 그 이상은 GPS 점프 |
| 이동 중 | 걷기 ≥ 0.3 · 자전거 ≥ 0.5 m/s | 정지(횡단보도 대기)는 Phase 4 가 맡으므로 뺀다 → OTP speed(이동 속도)와 같은 의미 |
| trip 값 | 이동 중 쌍의 중앙값, 쌍 12개(1분) 미만이면 미반영 | robust median |
| 프로파일 | `(n0·μ0 + Σ v_trip) / (n0 + n)`, n0 = 5 | 첫 trip 이 1/6 만 움직인다. `speed_profiles.sum_speed_mps` 가 Σ |

OTP 의 bicycle speed 는 평지 이동 속도 정의라 GPS 이동 중 중앙값과 의미가 맞는다(계획 v2 의 "관측/예측 비율 보정 계수"는 두지 않았다 — 실기기 자료가 쌓이면 판단).

## 개인정보

- 궤적은 서버가 발급한 trip id 로만 받고, 원본은 30일 뒤 지운다(`speed.PurgeOldTraces`, api 기동 후 1시간마다, 샘플 `ts` 기준. 그래서 서버 시각보다 5분 넘게 미래인 `ts` 는 업로드에서 400). trip 별 속도와 프로파일만 남는다.
- 탈퇴(`DELETE /users/me`)는 trip 을 지우고 traces 는 `ON DELETE CASCADE` 로 같이 사라진다(테스트로 확인).
- 앱은 백그라운드 위치 권한을 요구하지 않는다(`ACCESS_FINE_LOCATION`/`COARSE` 만). 화면을 벗어나면 수집이 멈춘다.

## 알려진 한계

- 화면이 꺼지거나 다른 앱으로 가면 샘플이 끊긴다(백그라운드 위치 권한을 쓰지 않는 결정). 30초 넘게 비면 그 구간은 학습에서 빠진다.
- 구간 자동 넘김은 끝점 40m 반경 하나뿐이다. 경로를 벗어나도 재탐색하지 않는다.
- 실기기 궤적으로 상수(정확도 30m·이동 중 임계·반경 40m)를 재보정하지 않았다.
- 대중교통 leg 안의 걷기(환승 통로)는 transit 으로 태그돼 학습에 안 들어간다.
- 뒤로가기로 안내 화면을 나가면 그 안내는 종료 없이 버려진다(대기 샘플 유실, 서버 trip 은 `ended_at` 없이 남지만 무해 — 30일 뒤 궤적 삭제·탈퇴 시 삭제는 그대로). 뒤로가기를 종료로 볼지는 미결.
