# 안내 내비게이션

안내는 화면이 아니라 `GuideSession`이 소유합니다. 화면을 닫고 다른 경로를 검색해도 세션은 유지되며, 홈의 현재 경로 탭에서 다시 열 수 있습니다.

## 구성

| 파일 | 책임 |
|---|---|
| `guide_session.dart` | 위치·활동 스트림과 안내 수명주기 조정 |
| `leg_tracker.dart` | 현재 구간과 시간표 기반 구간 전환 |
| `step_tracker.dart` | 도보·자전거 단계 진행 |
| `stop_tracker.dart` | 대중교통 남은 정거장 |
| `instruction.dart` | 화면·음성 안내 문구 |
| `guide_overlay.dart` | 다른 앱 위에 표시하는 미니 지도·안내 데이터와 UI |
| `off_route.dart` | 도보 경로 이탈 판정 |
| `arrival_detector.dart` | 목적지 도착 판정 |
| `trace_uploader.dart` | 위치 샘플 배치 업로드 |
| `guide_store.dart` | 진행 중 안내 저장·복원 |

서버는 도보·자전거 leg에 `steps`, 대중교통 leg에 `stops`와 `headsign`을 내려줍니다.

도보·자전거 안내는 도로명 대신 다음 회전까지의 거리와 회전 동작을 기본으로 말합니다. 서버는 회전점 30m 안의 지하철역·학교·은행·공공기관·병원·대형마트 중 가장 가까운 시설을 찾아 주며, 있으면 `우리은행 근처에서 우회전`처럼 보강합니다. 현재 회전과 다음 두 회전을 미리 조회하고, 2초 안에 결과가 없으면 거리 안내로 즉시 시작합니다. 외부 장소 조회가 실패해도 안내 자체는 중단되지 않습니다.

## 다른 앱 위 미니 지도

설정에서 선택적으로 켭니다(안내 중에 켜고 저장해도 그 안내에 바로 반영됩니다). Android `TYPE_APPLICATION_OVERLAY` 창 두 개를 씁니다: 미니 지도 본체는 `FLAG_NOT_TOUCHABLE`로 터치를 아래 앱에 통과시키고, 오른쪽 위의 작은 진하기 손잡이(32dp)만 터치를 받습니다 — 누르면 슬라이더 띠가 펼쳐져 진하기를 20~80%로 바꾸고, 바깥을 누르거나 4초 두면 접힙니다. 기본 진하기는 50%이며 기기의 터치 상한(`maximumObscuringOpacityForTouch`, 보통 0.8)으로 한 번 더 자릅니다. 안내 중 홈이나 다른 앱으로 이동하면 현재 구간 미니 지도·현재 안내·다음 안내·남은 시간·도착 예정 시각이 나타나고, 서울길찾기로 돌아오거나 안내를 끝내면 숨습니다. Android 시스템의 "다른 앱 위에 표시" 권한이 필요합니다.

## 구간 진행

위치 정확도가 기준 안에 있고 구간 끝에 접근하면 다음 구간으로 이동합니다. 지하처럼 위치가 끊기면 계획 시각을 사용합니다. 사용자는 이전·다음 구간 버튼으로 현재 구간을 바로잡을 수 있습니다.

열차가 늦어지면 실제 탑승 가능한 출발을 선택해 이후 구간의 시각과 도착 예정 시각을 이동합니다. 남은 정거장은 위치와 시간표를 함께 사용합니다.

## 경로 이탈

도보 구간에서만 계획 폴리라인과의 거리를 확인합니다. 연속 표본이 이탈 조건을 만족하면 현재 위치부터 해당 구간 도착점까지 도보 경로를 다시 요청합니다.

- 재탐색 중 구간이 바뀌면 늦게 온 결과를 버립니다.
- 실패하면 원래 경로를 유지합니다.
- 재탐색은 1분보다 자주 실행하지 않습니다.
- 대중교통과 따릉이는 노선·대여소가 고정되어 있어 자동 재탐색하지 않습니다.

## 저장과 종료

trip 발급 뒤 안내 스냅샷을 저장하고 구간이 바뀔 때 갱신합니다. 앱이 다시 실행되면 저장된 trip과 구간을 복원합니다.

마지막 구간에서 목적지 도착 조건을 만족하거나 사용자가 종료하면 남은 샘플을 전송하고 서버 trip을 닫습니다. 전송할 샘플이 남거나 종료 API가 실패하면 세션을 유지해 다시 시도할 수 있게 합니다.

에뮬레이터에서는 `adb emu geo fix <lon> <lat>`로 경로를 따라 위치를 주입합니다. 다음 흐름과 콘솔 오류를 확인합니다.

1. 안내 시작과 첫 음성·알림
2. 도보 단계와 대중교통 정거장 전환
3. 화면 이동 뒤 현재 경로 복귀
4. 도보 이탈 재탐색 성공·실패
5. 앱 재실행 뒤 안내 복원
6. 목적지 자동 종료와 수동 종료 재시도
7. 다른 앱 전환 시 오버레이 표시·터치 통과와 앱 복귀 시 숨김
