# 지하철 빠른 하차

지하철 하차역에서 계단·상행 에스컬레이터와 가까운 칸-문을 안내합니다.

## 데이터 생성

```powershell
Set-Location backend
go run ./cmd/fastexit
```

명령은 다음 자료를 `otp/data/`에 저장합니다.

- 공공데이터포털 빠른하차정보 → `fast-exit.json`
- 서울 열린데이터광장 에스컬레이터 현황 → `escalator.json`

`DATA_GO_KR_KEY`가 필요하고, 에스컬레이터 방향에는 `SEOUL_OPENAPI_KEY`가 필요합니다. 서버는 기동할 때만 파일을 읽습니다.

## 동작

`backend/internal/fastexit`은 노선·역·진행 방향으로 자료를 찾고 다음 순서로 반환합니다.

1. 상행 에스컬레이터
2. 계단
3. 환승통로 상행 에스컬레이터
4. 환승통로 계단

앱은 상세 화면과 안내 화면의 지하철 하차 구간에 칸-문과 설비를 표시합니다. 자료가 없거나 방향을 확정할 수 없으면 표시하지 않습니다.

## 제한

- 원천 자료가 있는 노선과 역만 지원합니다.
- 엘리베이터는 빠른 하차 후보에서 제외합니다.
- 설비 공사·운휴 상태는 실시간으로 반영하지 않습니다.
