# 자전거 경로 설정

백엔드는 OTP 요청마다 다음 선호를 보냅니다.

- 최적화: `SHORTEST_DURATION`
- 자전거를 끌고 걷는 비용: `walk.cost.reluctance = 2.0`
- 속도: 사용자 학습값이 있으면 `BikeOTPSpeed`로 변환하고, 없으면 5.0m/s

OTP 기본 `SAFE_STREETS`는 자전거 도로를 우선해 더 오래 걸리는 경로를 선택할 수 있습니다. 기본 끌기 비용 5.0은 `bicycle=dismount`인 한강 다리 보도를 회피해 큰 우회를 만들 수 있어 2.0을 사용합니다.

## 측정

서울 주요 역 사이 자전거 단독 경로를 비교할 때 다음 값을 확인합니다.

- 경로 거리 ÷ 직선거리
- 경로 거리 ÷ 소요시간
- 끌기 비용 변경 전후의 경로선
- 대여·반납 도보 구간 포함 여부

현재 보정 계수 `bikeEffective = 0.89`는 OTP가 반환한 실효 속도와 요청 속도의 비율입니다. 경로 데이터나 OTP 버전을 바꾸면 같은 OD 집합으로 다시 측정합니다.

## 제한

- 속도 학습 표본이 없을 때 쓰는 5.0m/s와 학습 사전값 3.5m/s의 근거가 다릅니다.
- 도로 통행 가능 여부는 OSM 태그와 OTP 해석에 의존합니다.
- 따릉이 재고는 지금 출발 요청에만 반영됩니다.
